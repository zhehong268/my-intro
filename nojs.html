无 JS 对照

左右两框装的是同一份 index.html：左边那个 iframe 带 sandbox 属性、 没有 allow-scripts，等于浏览器层面禁用脚本；右边正常加载。 整站的默认样式就是终态 —— 数字直接是 5 / 3 / 9 / 8，技能条直接是最终长度，所以左边一样能读完。

← 回主页 内核控制台 单独打开主页（新标签）
LEFT · <iframe sandbox> —— 禁用脚本
RIGHT · <iframe> —— 脚本正常执行

自检中…（这一段是脚本写的；脚本没跑，这一行就一直是「自检中…」）

两边差在哪

项目左边（禁脚本）右边（有脚本）
入场门直接是正文（html:not(.js) .landing 隐藏）先封面，点「进入主页」
正文全都在，可滚动读完一样都在，多一层入场动画
统计数字直接是终值 5 / 3 / 9 / 8从 0 滚到终值
技能条直接是最终长度从 0 长出来
实时时钟隐藏（没有时间就没有意义）每秒走字
音游看到说明与静态画布，不跑动画跑起来，可挑战 64 个音符
背景音乐不加载（preload="none"）进入后可播放
滚动进度条 / 导航高亮不显示随滚动更新
做法：默认样式写成终态，脚本跑起来才在 <html> 上加 js 标记， 再由 html.js … 这些规则把「入场 / 从 0 开始 / 隐藏」的状态叠上去。脚本挂了，页面退回默认样式，内容不会少一行。
